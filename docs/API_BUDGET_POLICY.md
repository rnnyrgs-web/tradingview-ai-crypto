# OpenAI API budget policy

The autonomous API research lane is bounded to a USD 30 monthly project ceiling.

- Target average: about USD 1/day when high-value work exists.
- Runner monthly allowance: USD 29.
- Safety buffer: USD 1.
- GPT-5.6 Luna is the default model for routine autonomous research.
- GPT-5.6 Sol remains disabled in this bounded lane.
- Unused daily allowance is not a quota to burn.
- Deterministic Python, cached evidence, public/free data and early rejection should be used before paid model calls.
- Paid reasoning is prioritized for genuine resolved-prediction error diagnosis, high-information falsifiable hypotheses, selective WAIT/abstention, calibration/regime evidence, and timestamp-safe predictive-data work.
- Natural-history blockers such as pure ACC-002 InsufficientHistory must not consume repeated API cycles without materially new evidence.

The external OpenAI organization hard spend limit remains the final backstop and should remain at USD 30/month.
