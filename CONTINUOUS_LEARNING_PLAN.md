# Continuous Learning Rollout

Phase 1 (this branch): build the research-only learning core, wrong-signal diagnostics, prioritized research questions, a read-only runner over genuine resolved prediction-ledger rows, and bounded reusable lesson memory.

Phase 2: wire the learning runner into the bounded worker army without increasing heavy concurrency. It should run as a light research task, write compact advisory evidence, and never change production parameters automatically.

Phase 3: expose learning diagnostics through authenticated research observability so the hourly AI development cycle can consume the same lessons and choose higher-information experiments.

Phase 4: future prediction-ledger rows may be enriched only with timestamp-safe pre-forecast agreement/provenance fields. Historical rows must never be backfilled with fabricated evidence.

Phase 5: challengers generated from lessons must remain predeclared, fingerprinted, research-only and pass the full canonical validation chain before any production consideration.
